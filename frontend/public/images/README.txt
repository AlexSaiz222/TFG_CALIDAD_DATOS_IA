Para usar tu propia imagen como logo:

1. Coloca tu archivo de imagen en esta carpeta con el nombre "logo.png"
2. Asegúrate de que la imagen tenga un tamaño adecuado (recomendado: 200x200 píxeles)
3. Si prefieres usar otro formato (jpg, svg, etc.), modifica la ruta en el archivo MainLayout.tsx
   - Busca la línea: const logoPath = '/images/logo.png';
   - Cámbiala por: const logoPath = '/images/tu-archivo.extensión';
