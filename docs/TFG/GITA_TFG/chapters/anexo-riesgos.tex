\chapter{Análisis retrospectivo de riesgos}
\label{anx:riesgos}

Este anexo amplía el análisis retrospectivo de riesgos resumido en la
sección~\ref{sec:riesgos} con el detalle de ocurrencia de cada riesgo y
las acciones correctivas efectivamente aplicadas durante el proyecto,
reconstruidas a partir de las incidencias documentadas en las
retrospectivas de cada sprint.  Conviene recordar que no existió un
registro formal de riesgos mantenido durante el desarrollo: las
prácticas preventivas que se enumeran fueron las que se aplicaron de
manera implícita en el flujo de trabajo diario, y las acciones
correctivas se decidieron \emph{ad hoc} cuando aparecía la incidencia.

\textbf{Resumen de ocurrencia:} de los ocho riesgos reconstruidos,
tres se materializaron de forma significativa (R-02, R-03, R-08), uno
ocurrió de forma menor (R-05) y uno tuvo un efecto positivo (R-01).
Los tres riesgos restantes (R-04, R-06, R-07) no llegaron a producirse,
lo que resulta coherente con las prácticas preventivas que se aplicaron
implícitamente en el flujo de trabajo.
